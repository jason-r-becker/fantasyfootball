# Fantasy football tools

Python tools for preparing fantasy-football rankings, running a local,
read-only draft companion, and doing in-season lineup analysis.

The draft room reads picks from Sleeper or ESPN and tracks them locally. It
never submits a pick to either platform.

## Install

Requirements: Git, [uv](https://docs.astral.sh/uv/getting-started/installation/),
and Python 3.12 or newer (uv can install the required Python version).

```bash
git clone https://github.com/jason-r-becker/fantasyfootball.git
cd fantasyfootball
uv sync
```

Run all commands from the repository root.

## Prepare a league

Choose a short league name containing letters, numbers, underscores, or
hyphens, then create its directory:

```bash
mkdir -p data/YEAR/LEAGUE
```

The fastest setup is to receive or prepare these two files:

```text
data/YEAR/LEAGUE/config.json
data/YEAR/LEAGUE/clean.csv
```

`adp.csv` in the league directory and
`data/YEAR/source_player_map.json` are optional but recommended.

The repository can generate several of these artifacts:

| File | How it is obtained |
| --- | --- |
| `config.json` | Copy and edit [the example](examples/sleeper-config.example.json), or let `clean_data.py` create a minimal draft-preparation config interactively. Platform IDs, rounds, and draft slot still need to be added. |
| `raw.csv` | Generated by the R projection script when a season scoring profile is available. |
| `adp.csv` | Downloaded separately; the repository does not currently generate it. |
| `clean.csv` | Generated by `clean_data.py` from `raw.csv`, `adp.csv`, and `config.json`. |
| Draft state and working CSVs | Generated automatically when the draft room starts and as picks are recorded. |

See [Data preparation](docs/data-preparation.md) for the complete input/output
workflow.

## Run the draft room

Set `draft_slot` in `config.json`, or provide it with `--pick`. Rehearse in
practice mode:

```bash
uv run fantasy-draft \
  --year YEAR \
  --league LEAGUE \
  --practice \
  --pick DRAFT_SLOT
```

Start the real draft explicitly with:

```bash
uv run fantasy-draft \
  --year YEAR \
  --league LEAGUE \
  --live \
  --pick DRAFT_SLOT
```

The browser opens at the URL printed in the terminal. Practice and live state
are separate. Live mode polls the configured platform every three seconds;
manual tracking remains available if the API is delayed or offline.

## Login and environment variables

Sleeper synchronization uses its public read-only API. It needs a `draft_id`
and optionally `user_id` and `league_id`, but no Sleeper password, API token,
or environment variables.

ESPN public leagues need no login. Private ESPN leagues may require `swid` and
`espn_s2` values in the league's `config.json`.

The projection and cleaning scripts do not read environment variables. A
[tracked `.env.example`](.env.example) exists to make that explicit; it has no
required values. The FantasyPros ADP export is obtained outside the repository.
